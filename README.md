# MyFunList

MyFunList is a media tracking app in development. Discover books, movies, and TV shows, and keep a personal book Library in this browser.

The planned public domain is `myfunlist.app`. Its deployment status is not confirmed.

## Local development

Run `npm install`, copy `.env.example` to `.env`, and start the app with `npm run dev`. A Google Books API key is optional for local book search. Movie and TV search requires a TMDB API Read Access Token in `VITE_TMDB_API_TOKEN`.

Run `npm run build` to verify the production build.
